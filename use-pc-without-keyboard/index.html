How to use a PC without a keyboard

A dead keyboard blocks you earlier than a dead mouse does — usually at the password field, before Windows has even loaded. That has a fix, and it is the first thing on this page.

Updated 25 August 2026 · Windows 10 and 11 · Steps verified against Microsoft's documentation

First: get past the sign-in screen

If you cannot type your password, nothing else on this page matters yet. Windows keeps an accessibility menu on the sign-in screen for exactly this, and it works before you are logged in.

  1. Click the button in the lower-right corner

    On Windows 11 it is labelled Accessibility; on Windows 10, Ease of Access. It sits next to the power button.

  2. Choose On-Screen Keyboard

    A clickable keyboard appears over the sign-in screen.

  3. Click your password in

    Click the password field first so it has focus, then click the characters. Shift and Caps are on the on-screen keyboard too — click Shift and it stays held for the next character.

If your PC signs in with Windows Hello — a face, a fingerprint or a PIN pad you can click — use that instead. It is faster and it sidesteps the problem entirely.

Inside Windows: the On-Screen Keyboard

Once you are logged in, the same keyboard is one shortcut away — assuming you have some working keys. Otherwise reach it through Settings with the mouse.

Opening the On-Screen Keyboard
MethodSteps
Win + Ctrl + OTurns the On-Screen Keyboard on. Press it again to turn it off.
Settings, Windows 11Settings → Accessibility → Keyboard, then turn on On-Screen Keyboard.
Settings, Windows 10Settings → Ease of Access → Keyboard, then turn on the On-Screen Keyboard toggle.
SearchClick Start, type osk, open it. Works if the mouse is fine and the search box can be clicked.

The On-Screen Keyboard is a real keyboard as far as Windows is concerned: modifier keys latch when you click them, so Ctrl then C copies, and Ctrl Alt Del works. It is not a touch keyboard — it is designed to be clicked with a pointer, which is precisely your situation.

Typing without pressing keys

Voice typing

Win + H opens voice typing: click into any text field, start it, and speak. It handles punctuation by name — say comma, full stop, new line. For longer stretches this is far quicker than clicking a keyboard letter by letter. It needs a microphone and, for the initial download of the speech model, an internet connection.

If you want to run the whole machine by voice rather than just dictate into a box, Windows 11 has Voice access under Settings → Accessibility → Speech — it takes commands like "open Chrome" and "click Save" as well as dictation.

Copy, paste and special characters with the mouse alone

  • Right-click instead of Ctrl+C. Every context menu carries Cut, Copy, Paste, Rename and Delete. Nothing about clipboard work requires a keyboard.
  • Emoji and symbols: Win + . opens the emoji panel, which also has symbols, currency signs and kaomoji — clickable, searchable.
  • Accented and unusual characters: open Character Map from Start, find the character, copy it. This is how to type é or ° or → with no keyboard at all.
  • Passwords you cannot remember clicking: if a password manager is installed, let it fill the field. Fewer characters clicked is fewer chances to mistype.

Where this runs out

Nothing on-screen exists before Windows starts. The BIOS or UEFI setup screen, the boot menu, a Press F2 to enter setup prompt, or a full-disk-encryption password — all of those run before Windows loads and need real keyboard hardware. If that is where you are stuck, you need a physical keyboard; a USB one from any shop will be detected without drivers.

It covers what you are typing into. The On-Screen Keyboard is a floating window that takes up the bottom third of the screen, and it lands on top of the thing you are writing in. You can drag it, but you are trading screen space for typing.

No rollover, no gaming. Clicking one key at a time cannot express W + Shift + Space held together, and games generally ignore synthetic key events anyway.

A full keyboard, on your phone

If you have an Android phone, PCDeck puts a complete keyboard on it and sends the keystrokes to your PC. The difference from Windows' own On-Screen Keyboard is concrete, not cosmetic: it is on a second screen, so it never covers the document you are typing into, and it includes a numeric keypad and modifier keys that latch — Ctrl, Alt, Shift, function keys, arrows.

The same app is also a trackpad, so if the keyboard and the mouse both went at once you are covered. Everything runs over your own Wi-Fi with no account and no internet, and the keyboard and trackpad are free.
