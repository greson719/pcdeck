How to use a PC without a mouse

Your mouse or touchpad has stopped working and there is no spare in the house. Windows can be driven entirely from the keyboard — and there is a built-in feature that turns the numeric keypad into a pointer. Here is what works, in the order you need it.

Start with focus: Tab, arrows, Enter

Everything below rests on one idea. Windows always has an element in focus — the button or field that would react if you pressed a key right now. A mouse moves focus by pointing. Without one, you move it by stepping.

Moving focus and acting on it
KeysWhat it does
TabMove forward to the next control. Shift + Tab goes back.
↑ ↓ ← →Move within the thing that has focus — a list, a group of radio buttons, a page.
EnterActivate what is focused. This is your left click.
SpaceTick a checkbox, or press a focused button.
F6Jump between the large regions of a window — sidebar, file list, address bar. Faster than tabbing thirty times.
EscClose the menu or dialog you are in.

If you get lost, Esc then F6 is a reliable reset: close whatever popped up, then walk the window's regions one at a time.

Open anything without clicking it

You do not need the Start menu's tiles or a desktop icon. Press Win, type the first few letters of the program's name, and press Enter. Search takes focus automatically, so there is nothing to click first — this one habit replaces most of what a mouse did.

Right-click without a right button

Half of Windows lives in context menus: rename, copy, delete, properties, Open with. You can reach all of it.

Shift + F10 opens the context menu for whatever is focused. Many keyboards also have a dedicated Menu key — a small icon of a list, usually between the right Alt and right Ctrl — which does the same thing in one press. Once the menu is open, arrow down to the entry you want and press Enter.

Move the pointer with the numpad: Mouse Keys

Some things genuinely need a pointer. Windows has shipped a feature for exactly this since long before touchscreens existed, and it is still in Windows 11: Mouse Keys turns the numeric keypad into a mouse.

  1. Press Left Alt + Left Shift + Num Lock

    Use the Alt and Shift keys on the left side of the keyboard — the shortcut ignores the right-hand ones. Windows asks whether you want to turn Mouse Keys on; press Enter to confirm. The same shortcut turns it back off.

  2. Make sure Num Lock is on

    Mouse Keys can be configured to work only while Num Lock is on, and that is the usual default. If the pointer will not budge, press Num Lock once and try again.

  3. Move: 8 up, 2 down, 4 left, 6 right

    On the numeric keypad. 7 9 1 3 move diagonally. Hold a key to keep travelling; it accelerates as it goes, so short taps are for fine positioning and long holds cross the screen.

  4. Pick the button before you click

    / selects the left mouse button, - selects the right, * selects both. The choice stays until you change it, so set it to left once and forget it.

  5. Click with 5. Drag with 0 and the decimal point.

    5 clicks the selected button. To drag: move onto the item, press 0 to hold the button down, move to the destination, then press . to release.

The speed and acceleration are adjustable. Press Win + U to open accessibility settings — on Windows 11 that is Settings → Accessibility → Mouse; on Windows 10 it is the Ease of Access Center, under Make the mouse easier to use. Turn the pointer speed up if crossing a large monitor feels like wading.

The catch

Mouse Keys needs a numeric keypad. Most laptops and every compact tenkeyless keyboard do not have one. Some laptops overlay a numpad on the letter keys behind an Fn lock; many no longer do. If you are on a laptop with no numpad, this section is not available to you — use your phone as a trackpad instead.

Where keyboard-only stops being enough

The shortcuts above will get you through an afternoon. They will not replace a mouse, and it is worth knowing where the wall is before you hit it:

  • Anything aimed at a specific pixel. Resizing a window by its edge, dragging a slider to a precise value, selecting a region in an image editor. Mouse Keys can do these, at roughly a tenth of the speed.
  • Drag and drop between windows. Rearranging a playlist, dropping an attachment onto an email, moving a layer.
  • Web pages built without keyboard support. A custom dropdown or map that only responds to hover leaves Tab with nothing to land on.
  • Games and creative software. Continuous aiming and drawing are pointer input by nature. There is no shortcut for them.
  • No numpad, no Mouse Keys. On a laptop, the single best built-in option is simply unavailable.
