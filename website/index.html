Before you install

Why Windows and Android will warn you

PCDeck is not distributed through the Microsoft Store or Google Play. Both systems warn about any software that arrives that way. Here is exactly what you will see and what it means.

Read this first

The warnings are about publisher reputation, not detected malware

PCDeck is distributed independently outside the Microsoft Store and currently lacks an enterprise EV code-signing certificate. Windows Defender SmartScreen treats newly released unsigned executables as having unknown reputation on first launch, and Android prompts for unknown sources permission when sideloading an APK.

These warnings occur because the software is distributed directly rather than through commercial app stores; they do not by themselves establish that the file is malicious. Always verify the published SHA-256 checksum against your download, or inspect the PCDeck Security Architecture for network isolation details.

Windows
SmartScreen

“Windows protected your PC”

A blue dialog appears the first time you run the executable. This is Microsoft Defender SmartScreen reporting that the file is new and unsigned — it has no download reputation yet, and reputation is earned by volume over time.

To continue: click More info, then Run anyway.

Windows
Defender / AV

An antivirus flags it

PCDeck captures the screen, generates mouse and keyboard input, and opens a port on your local network. Because these native remote-control capabilities resemble patterns analyzed by heuristic scanners, unsigned utilities are occasionally flagged as false positives.

If flagged by your scanner: verify that the file came from the official PCDeck download, compare its SHA-256 checksum, review the detection details, and only override the warning if you understand and trust the software.

Windows
Firewall

“Allow PCDeck to communicate on this network”

On first run Windows Firewall asks whether to permit network access. PCDeck needs this — it is how your phone reaches your PC.

Tick Private networks and allow it. You can leave public networks unticked.

Android
Unknown sources

“Install blocked” / “unsafe app”

Android blocks sideloaded APKs until you grant permission once, per app that does the installing. Open the downloaded APK and, when prompted, allow Install unknown apps for the browser or file manager you downloaded it with.

If Play Protect adds that the app was not scanned before, choose Install anyway. That notice means the app is not in Play's catalogue, which is expected here.

Verify
the download

Check the file yourself

Run this in PowerShell and compare the result with the published checksum:

Get-FileHash .\PCDeck.exe -Algorithm SHA256

If the hashes differ, delete the file and download it again. Do not run it.

FAQ

Questions people actually ask

Can I use a Windows PC if the monitor is broken or dead?

Yes — that is the main reason people install PCDeck. It streams the desktop to your phone and accepts touch as mouse input, so a machine with a cracked, dark or disconnected monitor stays fully usable. Set it to start with Windows and the phone can connect to a PC that never shows a picture locally. No second monitor or HDMI adapter is needed. Installing it before the screen fails is easier, so it is worth having in place ahead of time.

What can I use if my PC mouse or keyboard is broken?

PCDeck turns the phone into a multi-touch trackpad with left and right click, two-finger scrolling and drag, plus a full on-screen keyboard with a numpad. It covers pointer and typing well enough to finish what you were doing, needs no drivers on the PC, and works as an emergency replacement until the hardware is repaired. Windows also has built-in options that need no download at all — see how to use a PC without a mouse and how to use a PC without a keyboard.

Why does Windows say “Windows protected your PC”?

Because the executable is unsigned and new, not because anything harmful was found. PCDeck is distributed directly instead of through the Microsoft Store, so it has no code-signing certificate and no SmartScreen reputation yet. Click More info, then Run anyway. Verifying the SHA-256 checksum is a stronger check than the warning itself.

Why does Windows Defender or my antivirus flag PCDeck?

A wireless trackpad has to capture the screen, synthesise mouse and keyboard input and open a local network port. That combination looks like remote-access software to a heuristic scanner, and unsigned files get less benefit of the doubt. Those capabilities are the product working as intended. If the file is quarantined, restore it from your antivirus history and optionally exclude the PCDeck folder — after checking the checksum.

How do I install the APK when Android says install blocked?

PCDeck is not on Google Play, so Android needs one-time permission to install it. Open the downloaded APK and allow “Install unknown apps” for whichever browser or file manager you used. If Play Protect says the app was not scanned, choose Install anyway. You only grant this once.

Does PCDeck need an internet connection?

No. Everything runs on your local Wi-Fi, or on the phone's own hotspot if there is no router. There is no account, no cloud relay, no analytics and no telemetry, so screen contents and transferred files never leave your network.

Is PCDeck free, and what does the paid version add?

The free version covers trackpad gestures, the on-screen keyboard, 30 FPS screen streaming, PC audio streaming and the two-way file manager. A one-time $3.99 lifetime licence raises streaming to 60/120 FPS and unlocks faster transfers. There is no subscription, and the license activates directly with your order key.

Pro unlocks inside the app you already downloaded — there is no separate Pro build to hunt for. The APK below is the full app, free features first.

Can I control my PC from an iPhone, iPad, Mac or Linux?

Yes! PCDeck features a built-in Zero-Install Web Remote. When you launch PCDeck on your Windows PC, simply point your iPhone or iPad camera at the on-screen QR code (or navigate to your PC's local IP address in any browser). Safari or Chrome immediately opens the full touch controller with multi-touch gestures, on-screen keyboard, 60 FPS desktop streaming, PC audio receiver, and file manager — with zero app installation required.

Does PCDeck support Linux and Steam Deck?

Yes! PCDeck runs natively on Ubuntu, Debian, Fedora, Arch, Raspberry Pi OS, and SteamOS (Steam Deck). Simply run curl -sSL https://pcdeck.vercel.app/install.sh | bash in your Linux terminal to launch it immediately with multi-touch trackpad, keyboard, and screen streaming support.

Which Windows, Linux and Android versions are supported?

Windows 10 and Windows 11 as a standalone executable; Linux (Ubuntu, Debian, Fedora, Arch, SteamOS, Raspberry Pi) via universal 1-line script or binary; Android 5.0+ natively; and iOS/iPadOS/macOS via the instant Zero-Install Web Controller.

How does tapping the streamed screen click the right place?

The phone reports the touch coordinates, and PCDeck maps them onto your desktop resolution before issuing a native Windows mouse event at that point. Tapping a window, icon or button on the stream clicks that exact element.

Will it work on a weak Wi-Fi adapter or a cheap USB dongle?

Yes, and it is built expecting them. PCDeck watches the wireless link and reconnects on its own if it drops, renews the address if the network hands out a broken one, and resumes file transfers from where they stopped rather than starting over. Screen streaming quality can be lowered if the link is slow.
