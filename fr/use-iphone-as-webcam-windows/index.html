Guide Pratique · Windows 11 & 10

Utiliser un iPhone comme webcam sous Windows (Gratuit, Sans App, Sans Filigrane)

Transformez la caméra de votre iPhone ou iPad en une webcam HD sans fil pour votre ordinateur Windows. Fonctionne directement dans Safari via votre réseau Wi-Fi local — sans télécharger d'application sur l'App Store et sans aucun filigrane.

720p Gratuit vs 1080p 60 FPS Pro

• PCDeck Core (0 $ Gratuit) : Flux vidéo HD 720p avec 0 % de filigrane pour Discord, Zoom et Teams.
• PCDeck Pro (3,99 $ Achat Unique) : Qualité Studio 1080p à 60 FPS avec ultra-faible latence (contre Camo à 49,99 $/an).

Télécharger sur Microsoft Store Comparer Gratuit vs Pro ($3.99)

Guide de configuration en 3 étapes

  1. Lancer PCDeck sur le PC : Téléchargez PCDeck depuis le Microsoft Store ou lancez PCDeck.exe.
  2. Scanner le code QR : Ouvrez l'appareil photo de votre iPhone et scannez le code affiché sur l'écran de votre PC.
  3. Activer la webcam : Autorisez la caméra dans Safari, puis sélectionnez PCDeck Virtual Camera dans Zoom, Teams ou OBS.

Configuration dans vos applications

Zoom & Microsoft Teams

Dans les Paramètres > Vidéo, choisissez PCDeck Virtual Camera comme source de caméra.

Discord

Allez dans Paramètres utilisateur > Voix & Vidéo et sélectionnez la caméra PCDeck sous Paramètres vidéo.

OBS Studio

Ajoutez une source Périphérique de capture vidéo et sélectionnez PCDeck Virtual Camera.
