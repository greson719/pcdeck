Frequently Asked Questions

Everything you need to know about PCDeck and PCDeck Pro.

Does PCDeck require an active internet connection? +
No! PCDeck operates 100% on your local Wi-Fi network or phone's mobile hotspot. It requires zero internet access, has no cloud accounts, and transmits no telemetry data.
How does direct touchscreen clicking work in Screen Mirror mode? +
When you touch any window, icon, or button on the live screen stream, PCDeck translates your touch coordinates directly into high-precision native Windows Win32 cursor clicks at the exact desktop pixel location.
What is the difference between PCDeck Free and PCDeck Pro? +
PCDeck Free includes full trackpad gestures, live 30 FPS screen mirror, WASAPI audio streaming, dual file manager, and keyboard typing. PCDeck Pro unlocks high-refresh 60 FPS / 120 FPS streaming, uncapped Turbo multi-stream file transfers, and all 5 Chroma themes with a one-time lifetime license.
Which Android versions are supported? +
PCDeck is built with modern Android 16 (API 36) backward compatibility and supports all devices running Android 5.0 Lollipop through Android 16+.
